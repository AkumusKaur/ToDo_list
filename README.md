# ToDo_list

Цель проекта
Разработка программы на Python для ведения персонального списка задач с функциями добавления, просмотра, отметки выполнения и удаления задач. Обязательное использование ИИ-инструментов для валидации ввода и обработки ошибок.

Основные задачи

Функционал управления задачами:
 - Добавление новых задач (название, описание, срок, приоритет)
 - Просмотр списка с фильтрацией (все, активные, выполненные)
 - Отметка задач как выполненных
 - Удаление задач с подтверждением

Работа с данными:
 - Сохранение в JSON-файл (tasks.json)
 - Автоматическая загрузка при запуске
 - Восстановление всех полей задачи

Валидация ввода:
 - Проверка названия на пустоту
 - Корректность формата даты (ДД.ММ.ГГГГ)
 - Выбор приоритета из списка (высокий, средний, низкий)

Сортировка задач:
 - По сроку выполнения
 - По приоритету
 - По статусу

Использование ИИ:
 - Проверка корректности даты
 - Обработка ошибок файлов
 - Реализация подтверждения удаления

Дополнительные возможности (опционально)
 - Подсветка просроченных задач
 - Экспорт в текстовый файл или CSV
 - Поиск по названию задачи

Критерии оценки
 - Корректность всех операций с задачами
 - Надежное сохранение данных
 - Качественная валидация ввода
 - Удобный консольный интерфейс
 - Документация использования ИИ
 - Соблюдение PEP 8
 - Стабильная работа на разных данных
